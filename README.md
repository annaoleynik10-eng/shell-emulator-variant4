## Общее описание

Консольное приложение (CLI), которое имитирует работу командной строки
UNIX-подобной ОС. Язык реализации: Python 3.8+, без сторонних библиотек.

## Этап 1. REPL

- Приглашение строится по реальным данным ОС: `пользователь@хост:~$`.
- Парсер делит строку на команду и аргументы по пробелам.
- `ls`, `cd` - заглушки, выводят своё имя и аргументы.
- `exit [код]` - завершение работы с указанным кодом (по умолчанию 0).
- Неизвестная команда: `имя: command not found`.

## Этап 2. Конфигурация

Параметры командной строки:

| Параметр | Назначение |
|---|---|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script PATH` | путь к стартовому скрипту |

- При запуске выводятся все параметры (`[debug] vfs = ...`).
- Стартовый скрипт выполняется построчно, каждая команда печатается
  вместе с приглашением. Пустые строки и строки с `#` пропускаются,
  ошибочные строки пропускаются без остановки.
- Если в скрипте нет `exit`, после него начинается диалог.

## Запуск

```sh
./run.sh                                   # диалоговый режим
./run.sh --script tests/startup/stage2.txt # стартовый скрипт
./tests/sh/stage2.sh                       # проверка всех параметров
```

## Пример

```
anya@macbook:~$ ls -l /home
ls: args=['-l', '/home']
anya@macbook:~$ foo
foo: command not found
anya@macbook:~$ exit abc
exit: abc: numeric argument required
anya@macbook:~$ exit
```
